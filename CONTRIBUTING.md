# Contributing to Prompt Library Pro

Thank you for considering a contribution.

## Before you contribute

Please read:

1. [Prompt Library Pro Source Available Licence](LICENSE)
2. [Individual Contributor License Agreement](CLA.md)

**A signed CLA is required before a non-trivial contribution can be merged.** This includes source code, features, bug fixes, documentation, designs, artwork, tests, and other original project material.

## Contribution process

1. Open an issue first for substantial changes so the proposed work can be discussed.
2. Make your changes in your own fork and branch.
3. Keep each pull request focused and explain what changed, why it is needed, and how you tested it.
4. Identify any third-party code, assets, fonts, icons, or other material, including its source and licence.
5. Complete and sign the [Individual Contributor License Agreement](CLA.md).
6. Send the signed agreement to **eugph@gmail.com** with your GitHub username and pull request reference.
7. The Project Owner will confirm receipt. A pull request may be reviewed before that, but it will not be merged until the required agreement and rights checks are complete.

## What the CLA means

You keep copyright ownership of the original work you contribute. You grant Eugene Phillips, trading as MX Phillips, a broad, perpetual licence to use, modify, distribute, sublicense, and commercialise that contribution as part of Prompt Library Pro, including under future project licensing terms.

The CLA is a licence, not a copyright assignment. It does not make the Project Owner the exclusive copyright owner of your contribution. If a transfer of ownership is intended, that requires a separate written copyright assignment.

Do not submit work owned by an employer, client, or another person unless you have written authority to do so.

## Small changes

Please do not assume that a small change is automatically exempt. Ask the Project Owner if you are unsure whether a CLA is required.
