# Showcase

Screenshots of every live screen in Prompt Library Pro, for showing people the app.

- Open `index.html` in a browser for the gallery. It works straight from the folder, no server needed.
- `light/` and `dark/` hold the same 52 screens, numbered in the same order.
- Captured at 1440 by 900, double density, with the ten starter prompts and four sample boards. No real data.
- The full screen prompt viewer is not included: it does not open in the current build.

Retake after a visual change: run the app, capture each screen again at the same size and replace the files with the same names.
