Prompt Library, Build Progress

Live implementation tracker for the multi account and Prompt Components graph upgrade.

Built

  • Server side account records and per account SQLite stores
  • PBKDF2 HMAC SHA 256 password hashing with per account salts
  • HttpOnly SameSite session cookies, server side session records
  • Device trusted profile switching without exposing passwords to the client
  • Account creation, login, logout, profile editing, password change, recovery reset and deletion
  • Account scoped localStorage namespace to stop browser state leaking between profiles
  • Prompt graph persistence with nodes, edges, ports and relationships
  • New node canvas foundation, infinite pan and zoom, palette drag and drop, handles, branches, convergence, selection, duplication and undo/redo

Testing

  • Automated repository syntax and live browser checks are still running.
  • The current environment does not expose the requested Ultracode or subagent runtime, so those roles cannot be invoked from this session.
  • Next checks: Python compile, JavaScript syntax, account swap test, graph persistence test, invalid connection test, reload restoration.

Current weaknesses

  • Group metadata is currently visual and needs a persistence pass.
  • Connection editing and marquee selection need a deeper interaction pass.
  • Password recovery is intentionally offline, using a one time recovery code because this desktop build has no email service.
  • Real world hosted multi device authentication would still need a TLS backed identity service rather than this local Flask identity store.
