    Building agent teams

    Start here

    What is an agent block?One team member with one job: a Planner plans, a Writer writes, a Critic reviews. Each agent is its own block.
    What is the least I need?Two agents and one wire between them, for example Writer into Critic. That is already a team.
    Do I need a Conductor?No. It is optional. Use it when you want one block that briefs four agents from a single task.
    If I add a Conductor, do I still need the agent blocks?Yes. A Conductor only hands out work. Select it and press "Add its agents and wire them" to get all four in one go.
    Conductor, Team Lead or Router?Conductor briefs a fixed four. Team Lead splits a job across any three agents you choose. Router sends each request to one agent only. Use one at most.
    Does anything actually run?No. The builder writes a prompt. The AI you paste it into plays every agent in order, which is why the prompt spells out who hands what to whom.

    What a team does

    A team splits one job across specialised agents. Each agent has one job, its own rules, and labelled inputs and outputs. You wire an output of one agent into an input of the next, and the builder writes that wiring into the prompt: every agent's entry says who it receives from and who it hands to.

    Any block can join in. Core, data and logic blocks wire into agent inputs like any other block. A Style Guide can feed an Editor, a Quality Rubric can feed a Critic, and a Knowledge Source can feed a Researcher.

    Team shapes you can load

    Each card is a working tree. Load one, read the compiled prompt on the right, then swap agents in and out.

    The agent blocks

    Agents and reviewers do the work. Coordinators are optional and only hand it out. Select any block on the canvas to see its description and three things you can do with it.

    Loops

    • A loop is allowed when the return wire goes into a Feedback or Reports input. Those wires are drawn dotted and the prompt gains a "Revision loop" or "Reporting line" entry.
    • Any other circular link is treated as a mistake. It is drawn red and blocks the Ready badge.
    • Loops run for 2 rounds unless you say otherwise. Put a Feedback block on the return wire and set Max rounds to change it.

    Rules of thumb

    • Wire the task into more than one agent. The Writer and the Critic both need the original task, not only the plan.
    • Give the Critic the plan. Without it the Critic cannot tell whether the draft followed the plan.
    • Check facts before polishing. Fact-Checker first, Editor last.
    • End on an Output Format block. The team needs to know what the finished deliverable looks like.
    • Drag wires from either side. Start from an output or an input and the builder works out the direction.
