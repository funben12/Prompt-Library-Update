## Hard rules (from CLAUDE.md and the handover)
- Do not edit `static/app.js`, `static/index.html`, `static/app.css` or `static/workspace-registry.js`. The lead integrates those. You own only the new files named in your task.
- Use only tokens that exist in `static/app.css` `:root` (read lines 1 to 200). Light and dark via `:root[data-theme="dark"]`. Fonts: `--ff-display` Fraunces, `--ff-sans` Instrument Sans, `--ff-mono` JetBrains Mono for every number and count. No hex values. No gradients, textures or full bleed imagery. Glass (`--glass*`, `--blur-md`) only if those tokens exist; check with grep and say if absent.
- Icons: Material Symbols outlined spans (`material-symbols-outlined`). No emoji.
- Section labels: `--fs-xs`, weight 700, uppercase, letter-spacing 0.07em. Workspace names in Title Case, UI labels in sentence case. UK English. No dashes as punctuation in any visible text or comments.
- Every id and class gets your prefix, every CSS rule sits under your root element id. Listeners on your root. Any `document` keydown listener returns at once while your UI is closed.
- Mobile responsive: works at 390px wide. Touch targets at least 44px on touch layouts. Respect `prefers-reduced-motion`.
- Accessibility: dialogs use role=dialog and aria-modal, focus trap, focus returns to the opener on close, Esc closes, visible `:focus-visible` ring using `--ring`, WCAG AA contrast in light and dark.
- Workspace-style files follow the Builder Pro pattern: `static/builder-pro.js` and `static/builder-pro.css` are the reference (root element is filled once, `window.openXxxWorkspace` and `window.PL_closeXxx` exposed, `.open` class shows it, z-index `var(--z-modal)`, `animation: pl-ws-open`). Free users are refused by a `body.is-premium` check. Toasts via `window.PL_toast(msg, kind)`.
- No new dependencies, no network calls, no GitHub Actions. Plain JS in an IIFE, camelCase, one line plain English comments.
- Escape all user text before inserting into HTML. Wrap storage reads and writes in try/catch.
- Persistence: localStorage only, key prefixed with your workspace name.
