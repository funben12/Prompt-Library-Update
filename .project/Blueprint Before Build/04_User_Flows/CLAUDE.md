# 04_User_Flows — CLAUDE.md

## Purpose

Map the primary paths users take through the app. Retrospective — documents shipped flows, not proposed ones.

## Rules for Claude

- Only core flows are mapped (create/run prompt, licence activation, onboarding). Not exhaustive across all 17+ workspaces.
- Onboarding tour is fragile — six polish/fix entries in root MEMORY.md history. Treat any change near it as high-risk, verify manually.
- New workspace nav wiring must follow the fixed 4-step order in root CLAUDE.md Hard Rule 5 — a `data-view` button with no handler fails silently, which is a common source of "why doesn't this work" bugs.
