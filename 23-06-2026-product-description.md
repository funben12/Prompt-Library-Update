# Prompt Library Pro — Product Description

---

**What it is**

Prompt Library Pro is a Windows desktop application for storing, organising, and running AI prompts. Local-first, no cloud, no account, no subscription. Pay once and it's yours.

---

**What you get**

A searchable prompt library with folders, tags, categories, and colour labels. A variable system — `[[name]]`, `{{name}}`, `((name))` — that lets you fill and personalise any prompt with a live preview before you copy it. Chain prompting for multi-step workflows. A built-in AI executor with support for OpenAI, Anthropic, Gemini, and OpenRouter (bring your own key).

Pro unlocks ten specialist workspaces: Prompt Forge, Playground, A/B Lab, Components, Metaprompting, Optimizer, Tone Calibrator, Context Bank, and Snippets. Plus version history, analytics, bulk export, a command palette, and unlimited prompts, folders, and tags.

One licence. Lifetime access. No renewal, no tier creep.

---

**How to use it**

Download and run the installer. Your library is ready in under a minute. Start from 168 built-in prompt starters, import your own, or build from scratch. Fill variables, run with AI, build chains, export when you need to.

---

**Who it's for**

Prompt engineers, solo founders, and AI-focused professionals who are tired of losing prompts to browser tabs, Notion pages, and chat history. Built for people who treat prompts as working assets, not throwaway inputs.
