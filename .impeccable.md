# Prompt Library Pro — Design Context

> Recorded per the Impeccable Frontend Design context-gathering protocol.
> Locked 2026-04-26 with MX Phillips. Update only when product direction shifts.

## Audience
Freelancers, agency owners, and AI-curious professionals who use prompts
seriously as part of their craft — not casual dabblers. They reuse prompts
across clients/projects, refine them over time, and want a calm, trustworthy
home for that work.

## Use cases
- Save and refine a personal library of prompts
- Organise by folder, category, tag, colour, rating
- Detect variables, fill them, copy ready-to-paste
- Track usage so the most valuable prompts surface
- Version history; revert when an edit goes wrong
- Chain prompts into multi-step workflows
- Export / import for backup and sharing
- Operate as a desktop-class single-user application (offline-capable, local SQLite)

## Brand personality
Considered, literate, quietly confident. Premium but not flashy. The opposite
of "AI tool with neon gradients on dark mode." Reads as a writer's desk, not
a SaaS dashboard.

## Differentiator (the unforgettable thing)
**Prompts are treated like manuscripts.** Typography is the hero — display
serif on titles, refined sans on UI, monospace only where it earns its
place (the prompt content area). The aesthetic references editorial design
and quiet productivity tools rather than "AI app" tropes.

## Aesthetic direction: Editorial Workshop
- **Display font:** Fraunces (variable, optical sizing) — titles, prompt names
- **Body font:** Instrument Sans — UI, metadata, body
- **Monospace:** JetBrains Mono — prompt content textarea only
- **Palette:** OKLCH, warm-tinted neutrals (hue ~60–80), single ink-blue accent
  near `oklch(38% 0.13 245)`. Light theme is the default — dark theme is also
  refined (no glowing accents, no pure black).
- **Spacing:** 4pt scale, semantic tokens, fluid via `clamp()`
- **Motion:** 100/200/300ms with exponential ease-out, transform+opacity only,
  honour `prefers-reduced-motion`
- **Layout:** Asymmetric. Sidebar + main + slide-in detail panel. List view
  by default (cards as dense rows with a thin coloured rule). No nested cards,
  no glassmorphism, no gradient text.

## Anti-patterns to avoid (from the Impeccable skill)
- Inter / Roboto / system defaults
- Cyan-on-dark, purple→blue gradients, neon accents
- Pure black or pure white surfaces
- Glassmorphism, frosted glass, glowing borders
- Generic icon-+-heading-+-text card grids
- Hero metric template (big number, gradient, sparkline)
- Modals as default — only when truly necessary
- Animating layout properties; bounce/elastic easing
- "OK / Submit / Cancel" — every label says what it does
- Centering everything

## Technical constraints
- pywebview / WebView2 host (Chromium-equivalent recent — modern CSS available)
- Flask + SQLite backend (single user, local file)
- PyInstaller bundle, Inno Setup installer
- Desktop-only (1024×768 minimum, optimised for 1400×900+)
- All assets local; no CDN beyond Google Fonts (acceptable for offline-first
  desktop app since fonts cache after first launch; consider self-hosting later)
