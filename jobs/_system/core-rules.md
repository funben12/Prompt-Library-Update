# Core rules

Applied to every job on top of its rubric. Edit this file to change house rules everywhere.

## Hard checks
Read by lint.py. One rule per line, key: value.

```
no_dashes: true
banned: delve, landscape, evolving, insight, nuanced, paradigm, comprehensive, framework, facet, holistic, iterative, synergy, pivotal, robust, transformative, spectrum, trajectory, unlock, revolutionise, game changer, in conclusion, in summary, first and foremost
```

## Judgement checks
* Is it UK English throughout?
* Is it direct, with no padding or long introduction?
* Does every claim of fact appear in sources.md, or is it common knowledge?
